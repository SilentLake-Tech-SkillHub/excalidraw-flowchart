# 风格指南

本 Skill 的所有图都是同一种白板风(whiteboard explainer):彩色阶段标题、圆角分组框、图标和浅色块、紫色虚线表示判断、虚线表示回路。出图有两种方式,画出来风格一致:**手工构图**用于总览图(5 到 8 个元素,一眼看懂整体),**流程规格**用于细节流程(阶段加节点加连线,自动排版)。本文讲手工构图的规则,流程规格见 [flow-spec.md](flow-spec.md)。

## 什么时候用哪一种

| 场景 | 用哪种 | 原因 |
|---|---|---|
| README 开头、PPT、讲解用的总览 | 手工构图 | 元素少,可以挑图标、控制留白,最好看 |
| 逐步骤的细节流程、判断分支多、有回路 | 流程规格 | 自动排版和布线,改一行文字就能重画 |
| 手工构图的元素超过约 8 个 | 改用流程规格,或拆成多张 | 手动摆位置会越来越乱 |

## 构图规则

1. **从左到右摆 3 到 5 个阶段**,阶段之间用一根直箭头连接。
2. **每个阶段上方一个大号彩色标题**(30 号字),颜色循环:蓝、绿、紫、橙。
3. **阶段内容用图标表达**,不用文字框堆叠:
   - 文档 `s.doc()`、纸堆 `s.stack()`、数据库 `s.cylinder()`
   - 需要用户确认或有门禁的位置用紫色虚线块 `s.block(..., {dashed:true})`
   - 要强调"这里是一块"时用圆角大框 `s.frame()` 圈起来
4. **说明文字放在图标正下方**,同色、两行以内,用 `s.text(cx, y, ...)` 以中心点对齐。
5. **回路用虚线**,从后一阶段绕到前一阶段下方,旁边标一句话(如"要修改,回到填写")。
6. **留白**:阶段之间至少留 100 像素空隙;整张图宽约 1700、高约 750。
7. **浅色填充**:蓝色块用斜线纹理 `hachure`,其余用实色浅色;不用深色填充。

## 写法

新建 `xxx.build.mjs`:

```js
import { Scene, C } from "<到 scripts/compose.mjs 的相对路径>";
const s = new Scene();
s.text(560, 30, "图的标题", 44, C.gray);
s.frame(290, 210, 340, 480, { title: "第一阶段", color: C.blue });
s.block(370, 250, 180, 120, "文字", "blue", { hachure: true });
s.arrow(650, 410, 750, 410);
s.title(865, 250, "第二阶段", C.green);
s.doc(865, 320, "green");
s.save(new URL("./xxx.skeleton.json", import.meta.url).href);
```

然后 `node xxx.build.mjs && node scripts/render.mjs xxx.skeleton.json`。

## 坐标注意点

- 带 `textAlign: "center"` 的文字,`x` 是**中心点**,不是左边缘;`compose.mjs` 的 `text()` 已按此处理。
- 框内文字用 `block()` 的 `label`,会自动居中;框外说明用 `text()`。
- 说明文字不要压在框线或图标边缘上;画完必须看图检查。
- 颜色:蓝 `#1971c2`、绿 `#2f9e44`、紫 `#9c36b5`、橙 `#e8590c`、灰 `#495057`,在 `C` 与 `FILL` 里取。

## 自检清单

- [ ] 每个说明文字都和它所属的图形居中对齐
- [ ] 没有文字压在边框、箭头或图标上
- [ ] 阶段标题颜色各不相同,且和下方图标同色
- [ ] 回路箭头方向正确,旁边有文字说明
- [ ] 整张图一屏能看完,元素不超过 8 个
